# VIVA 0.3.0 beta 1 팀 테스트

팀원이 설치 파일을 내려받아 VIVA를 실행하고, GitHub 프로젝트를 clone해 작업할 수 있는 테스트 버전입니다. Node.js·npm·터미널 명령어는 필요하지 않습니다. **Git은 별도 설치가 필요하며**, VIVA가 그래픽 설치 안내와 작성자 이름·이메일 설정 화면을 제공합니다.

**사용 가이드 / User guides:** [한국어](https://github.com/yhkimslv/viva/blob/main/docs/user-guide.ko.md) · [English](https://github.com/yhkimslv/viva/blob/main/docs/user-guide.en.md). 설치부터 GitHub 연결·첫 clone까지 화면의 버튼 순서대로 진행할 수 있습니다.

이번 파일은 **미서명·미공증 팀 테스트용**입니다. macOS 앱에는 실행에 필요한 임시 서명만 적용했고 Apple Developer ID·공증과 Windows 게시자 인증서는 없습니다. 따라서 OS가 경고하거나 실행을 제한할 수 있습니다. 서명된 앱만 허용하는 관리 기기에서는 이 버전을 사용할 수 없습니다.

## 다운로드할 파일

| 팀원의 컴퓨터 | 다운로드 |
| --- | --- |
| Mac의 칩이 Apple M 시리즈 | [macOS Apple Silicon DMG](https://github.com/yhkimslv/viva/releases/download/v0.3.0-beta.1/VIVA-0.3.0-beta.1-mac-arm64.dmg) |
| Mac의 프로세서가 Intel | [macOS Intel DMG](https://github.com/yhkimslv/viva/releases/download/v0.3.0-beta.1/VIVA-0.3.0-beta.1-mac-x64.dmg) |
| Windows 64비트 PC | [Windows x64 설치 프로그램](https://github.com/yhkimslv/viva/releases/download/v0.3.0-beta.1/VIVA-0.3.0-beta.1-windows-x64-setup.exe) |

Mac은 **이 Mac에 관하여**에서 칩·프로세서를 확인할 수 있습니다. macOS 13 이상이 필요합니다. Windows ARM용 설치 파일은 포함하지 않습니다. 파일 무결성을 확인할 수 있는 `SHA256SUMS.txt`도 Assets에 제공합니다.

## 설치와 보안 확인

### macOS

1. 컴퓨터에 맞는 DMG를 열고 **VIVA**를 **Applications**로 드래그합니다.
2. Applications에서 VIVA를 엽니다.
3. 확인되지 않은 개발자·미공증 앱 안내가 나오면, 이 저장소의 테스트 파일임을 확인한 뒤 설치 여부를 직접 판단하세요. 허용 가능한 기기에서는 **시스템 설정 → 개인정보 보호 및 보안**의 개별 앱 확인 절차를 사용할 수 있습니다. [Apple의 공식 안내](https://support.apple.com/en-us/102445)를 따르세요.

### Windows

1. `VIVA-0.3.0-beta.1-windows-x64-setup.exe`를 엽니다.
2. 설치 마법사에서 설치 위치를 선택하고 설치를 완료합니다. 현재 사용자용으로 설치하며 관리자 권한을 요청하지 않습니다.
3. 바탕화면 또는 시작 메뉴의 **VIVA**를 엽니다.

Windows는 게시자를 확인할 수 없는 앱으로 표시할 수 있습니다. **Smart App Control**이나 조직 정책이 설치·실행을 차단하면 보호 기능을 해제하지 말고 관리자에게 문의하세요. 개별 앱 허용을 지원하지 않는 Smart App Control 기기에는 서명된 배포가 필요합니다. [Microsoft의 공식 설명](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)

## Git을 처음 설치하는 팀원

Git이 없다면 앱에 설치 안내가 표시됩니다. 이미 Git을 사용하는 팀원은 이 과정을 건너뛸 수 있습니다.

- **Windows:** [Git for Windows](https://gitforwindows.org/)에서 설치 프로그램을 내려받아 기본 옵션으로 설치합니다. VIVA 같은 다른 앱에서 Git을 사용할 수 있도록 기본 PATH 옵션을 유지하고, 설치 후 VIVA를 종료했다가 다시 엽니다.
- **macOS:** [Apple Xcode Resources](https://developer.apple.com/xcode/resources/)의 **Additional tools → View downloads**에서 Apple 계정으로 로그인합니다. 사용하는 macOS와 호환되는 **Command Line Tools for Xcode**의 DMG를 내려받아 안의 PKG 설치 프로그램을 실행합니다. 유료 개발자 멤버십은 필요하지 않습니다.

설치 후 VIVA의 **Git 설치 다시 확인**을 누릅니다. 설치 마법사와 앱 버튼으로 진행할 수 있으며 터미널 명령어는 필요하지 않습니다.

## 처음 프로젝트를 사용할 때

1. **GitHub에서 복제 / Clone from GitHub**에서 팀 저장소의 HTTPS 주소와 새 저장 폴더를 선택합니다. 공개 저장소는 로그인 없이 clone할 수 있습니다.
2. **프로젝트 설정 / Project Settings**의 작성자 설정에서 이름과 이메일을 확인하고 저장합니다. 해당 프로젝트에만 적용합니다. 이 정보는 이후 커밋과 업로드된 이력에 표시되므로 필요하면 GitHub의 비공개 이메일 주소를 사용하세요.
3. **Connect GitHub**로 연결하면 비공개 저장소와 리드 대시보드를 사용할 수 있습니다. 현재 원본 프로젝트에 설정된 OAuth 앱 이름은 **Git Abstraction Tool — Sean Lee(98sean)**이며 `repo` 권한을 요청합니다. 앱 이름과 권한을 확인하고 승인하세요. `repo`에는 비공개 저장소 읽기·쓰기가 포함됩니다. [GitHub 권한 설명](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/scopes-for-oauth-apps)
4. 작업 브랜치를 선택하고 변경사항을 저장합니다. PR 생성·리뷰·병합은 GitHub에서 진행하며, **리드 대시보드**는 PR·리뷰 요청·CI·담당 이슈를 읽기 전용으로 보여줍니다.

## 포함한 개선

- 앱 내 GitHub clone과 진행률·취소·기존 폴더 보호
- 실제 GitHub 데이터를 사용하는 리드 대시보드
- 반복 업로드, 기본 브랜치 보호, 동시 Git 작업, 충돌 해결 완료 흐름 개선
- 프로젝트별 AI 공유 동의와 자격 정보 보호
- 프로젝트별 작성자 설정과 그래픽 Git 설치 안내
- Electron 44와 갱신된 도구 체계, 의존성 보안 감사

릴리스 빌드는 각 OS의 감사·타입 검사·테스트를 거친 뒤 DMG 또는 NSIS 설치 파일에서 실제 앱을 설치·실행합니다. 세 설치본의 화면·IPC·프로필 격리 검사가 모두 통과한 경우에만 다운로드 파일과 체크섬을 함께 공개합니다.
