# VIVA 0.3.0 beta 2 — a new look for VIVA

![VIVA](https://raw.githubusercontent.com/yhkimslv/viva/v0.3.0-beta.2/assets/brand/viva-banner.png)

VIVA now has its own logo across the desktop app, macOS Dock, Windows and installer icons, and GitHub repository. This team preview keeps the GitHub clone, lead dashboard, and team workflow features from beta 1.

**User guides:** [English](https://github.com/yhkimslv/viva/blob/v0.3.0-beta.2/docs/user-guide.en.md) · [한국어](https://github.com/yhkimslv/viva/blob/v0.3.0-beta.2/docs/user-guide.ko.md). Follow the installation, GitHub login, and first-project steps in your preferred language.

No Node.js, npm, or terminal commands are needed. **Git must be installed separately**; VIVA provides graphical installation instructions and project-specific commit author settings.

**This is an unsigned/unnotarized team preview.** The macOS app uses an ad-hoc signature without Apple Developer ID signing or notarization. The Windows installer has no publisher certificate. OS warnings and managed-device restrictions still apply.

## Installation and OS warnings

- **macOS:** open the matching DMG, drag **VIVA** into **Applications**, then open it from Applications. If the developer cannot be verified, confirm the release source and decide whether to trust it. Where permitted, use Apple's per-app approval in **System Settings → Privacy & Security** after the first attempted launch. Follow [Apple's official guidance](https://support.apple.com/en-us/102445).
- **Windows:** open the EXE and complete the installation wizard. It installs for the current user without requesting administrator elevation. Start VIVA from the desktop or Start menu. Some SmartScreen prompts offer an individual confirmation after you verify the source. If Smart App Control or organization policy blocks this preview, contact your administrator; do not disable system protections. [Microsoft SmartScreen guidance](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation), [Smart App Control limitations](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions).

## Installing Git for the first time

Skip this step if Git is already available.

- **Windows:** use [Git for Windows](https://gitforwindows.org/) with the default PATH option so VIVA can find Git. Quit and reopen VIVA after installation.
- **macOS:** on [Apple Xcode Resources](https://developer.apple.com/xcode/resources/), select **Additional tools → View downloads** and sign in with your Apple Account. Download compatible **Command Line Tools for Xcode**, open its DMG, and run the PKG installer. A paid developer membership is not required.

Select **Check for Git again** in VIVA if the installation screen remains.

## Your first project

1. Before cloning a private repository, select **Connect GitHub → Login with GitHub** and approve the device code in your browser with your own account. The OAuth app remains **Git Abstraction Tool — Sean Lee (`98sean`)**. It requests the broad `repo` permission, including read and write access to private repositories your account can access. Check the app and permissions before approving. [GitHub's scope explanation](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/scopes-for-oauth-apps).
2. Select **Clone from GitHub**, enter your team's GitHub HTTPS repository URL, choose an existing parent folder and a new project folder name, then select **Clone and open**. Public repositories need no login; private repositories require a connected account with access.
3. In **Project Settings → Commit author**, check your name and email, then select **Save for this project**. This changes only the project's local Git settings. Your identity appears in future commits and uploaded history; you can use your GitHub private email.
4. Open **Lead dashboard** for a read-only view of PRs, review requests, CI, and assigned issues. Create, review, and merge pull requests on GitHub. Cloning and connecting do not automatically upload changes.
